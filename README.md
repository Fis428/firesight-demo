# 消防 Edge AI 多頁互動原型

靜態 HTML/CSS/JavaScript 原型，沿用既有首頁與品牌。無資料庫、登入、寄信、交易或持久儲存。

## 檔案
- index.html：原首頁與共用導覽、頁尾。
- pages.css：分頁版型及響應式樣式。
- app.js：固定內容、hash 路由、討論模擬、郵件及管理表單預覽。
- assets：原守護者標誌與展板擷取圖片。

## 頁面
首頁、計畫緣起、資源列表與四組介紹、設備列表與三個詳細頁、討論列表／發文／主題與回覆、成果列表與文章、聯絡郵件預覽、搜尋、購物車規劃提示、管理預覽。
商城無側欄。討論新增內容只存在當次記憶體；刷新即重置。

## 內容來源與待確認項目
林志學團隊、許志仲團隊、北瀚科技之介紹與圖片，依使用者提供的 2026 年 9 月「技術說明展板規劃_英飛凌 2026 CSR 公益捐贈記者會.pdf」第 3–5 頁整理。保留研發階段及測試情境限制。
守護者聯盟文字為專案討論整理之示意，正式介紹待確認。設備圖為概念示意；產品型號、售價、供應及交易方式未確認。活動正式稿、活動照片、文件下載與官網網址待補。

## 後續工程交接
確認內容欄位後再接資料庫與管理介面。需另實作身分驗證、管理權限、上傳、發文管理、持久儲存及寄信。管理預覽是公開示意路由，非受保護後臺。

## 已驗證
JavaScript 語法檢查；瀏覽器驗證首頁導航、資源呈現、示範發文與回覆、設備詢問帶入表單、郵件預覽、管理表單預覽。390px iframe 視覺檢查資源、商城與討論區。

## GitHub Pages 部署與維護
網站從 main 分支根目錄發布，無建置步驟。修改 index.html、pages.css、app.js 或 assets 後提交至 main，Pages 會自動更新。

本機預覽：在儲存庫目錄執行 `python -m http.server 8000`，開啟 http://localhost:8000。
