# 消防 Edge AI 開發平台｜互動示意原型

靜態 HTML/CSS/JavaScript 原型，沿用既有首頁與品牌。沒有資料庫，登入、發文、寄信都只在瀏覽器內模擬。
**給後端的交接說明請看 [HANDOFF.md](HANDOFF.md)。**

## 檔案
- `index.html`：頁首、頁尾與共用樣式。
- `data.js`：**所有內容都在這裡**（情境、成果、設備、團隊、討論、進度）。改內容只要改這個檔案。
- `app.js`：路由、各頁版面、互動（代表成果卡片列、情境切換、對照滑桿）與登入示意。
- `pages.css`：分頁與互動元件樣式。
- `assets/`：守護者標誌與展板擷取圖片。

## Round 1（2026-11）更新內容
- 導覽列簡化為：應用情境、成果、設備、關於・聯絡，右側是「技術交流」入口與登入。
- 首頁：雙入口（民眾看情境／技術人員進交流區）、代表成果改為可左右滑動的卡片列、情境切換加對照滑桿、計畫進度時間軸。
- 新增情境頁：上半部給民眾看，下半部可展開技術細節；與設備、團隊、討論互相連結。
- 設備頁合併原本的資源與商城，洽詢由 TGA 擔任窗口。
- 討論區：分類、情境篩選、排序、待回覆／已解答狀態、發文格式。
- 登入示意：用到才登入、第一次登入補填身分、登入後回原處、會員中心、管理員才能進後臺。頁尾可切換示意身分。

## 常見修改
- **新增代表成果**：在 `data.js` 的 `outcomes` 加一筆資料，設定 `featured: true`，首頁卡片列會自動多一張。
- **新增情境**：在 `scenarios` 加一筆資料，首頁、情境頁與搜尋會自動出現。
- **修改成熟度**：改該筆資料的 `maturity`（`done`／`test`／`research`）。
