# 消防 Edge AI 開發平台｜互動示意原型

靜態 HTML/CSS/JavaScript 原型。沒有資料庫，登入、發文、寄信都只在瀏覽器內模擬。
**給工程端的交接說明請看 [HANDOFF.md](HANDOFF.md)。**

## 檔案
- `index.html`：頁首（含應用情境下拉選單、手機選單按鈕）、頁尾與共用樣式。
- `data.js`：**所有內容都在這裡**（應用情境、技術模組、設備、合作團隊、計畫進程、討論）。改內容只要改這個檔案。
- `app.js`：路由、各頁版面、互動（下拉選單、代表成果卡片列、技術切換、對照滑桿、段落錨點）與登入示意。
- `pages.css`：分頁與互動元件樣式。
- `assets/`：守護者標誌、展板擷取圖片、交大提供的成果圖片與 Logo（`nycu-*`、`logo-*`）。

## 常見修改
- **新增應用情境**：在 `data.js` 的 `applications` 加一筆，下拉選單、總覽與搜尋會自動出現；沒填的區塊不會顯示。
- **設為首頁代表成果**：該筆設定 `featured: true`，並填 `name`、`headline`、`label`、`points`、`foot`。
- **新增合作單位**：在 `data.js` 的 `teams` 加一筆（`personLabel` 填主持人或聯繫窗口），合作團隊頁、首頁、搜尋與單位頁會自動出現。
- **更新合作團隊素材**：在 `teams` 填 `person`、`logos` 或 `url`，素材到齊後刪掉 `pending`，「素材待補」標籤就會消失。
- **更新計畫進程**：改 `progress` 的 `when`、`d`、`state`（`done`／`now`／`next`）。

## GitHub Pages 部署與本機預覽
網站從 main 分支根目錄發布，沒有建置步驟；合併至 main 後，Pages 會自動更新。
本機預覽：在儲存庫目錄執行 `python -m http.server 8000`，開啟 http://localhost:8000。
